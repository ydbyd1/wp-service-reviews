# Service Reviews & Ratings Plugin for WordPress

نظام تقييمات الخدمات المتقدم مع لوحة تحكم شاملة

## المميزات

✅ **نموذج تقييمات متقدم** - تقييم من 1 إلى 5 نجوم
✅ **جمع البيانات** - الاسم، الهاتف، البريد الإلكتروني
✅ **لوحة تحكم متقدمة** - إدارة كاملة للتقييمات
✅ **نظام الموافقة** - الموافقة على التقييمات قبل عرضها
✅ **تخزين آمن** - تخزين معلومات العملاء بأمان
✅ **عرض التقييمات** - Shortcode لعرض التقييمات على الموقع
✅ **الإحصائيات** - عرض إحصائيات التقييمات
✅ **متجاوب** - يعمل على جميع الأجهزة

## التثبيت

1. حمل الملفات إلى مجلد `/wp-content/plugins/wp-service-reviews/`
2. فعّل الإضافة من لوحة تحكم WordPress
3. ستظهر قائمة "تقييمات الخدمات" في القائمة الجانبية

## الاستخدام

### عرض نموذج التقييمات
```
[rating_form service="اسم الخدمة" title="اترك تقييماً"]
```

### عرض التقييمات الموافق عليها
```
[service_ratings limit="10"]
```

## لوحة التحكم

يمكن الوصول إلى لوحة التحكم من:
**تقييمات الخدمات** > في القائمة الجانبية

### التبويبات:
- **جميع التقييمات** - عرض جميع التقييمات
- **بانتظار الموافقة** - التقييمات التي لم تتم الموافقة عليها
- **الموافق عليها** - التقييمات المعروضة على الموقع
- **الإحصائيات** - إحصائيات عامة

## قاعدة البيانات

يتم حفظ البيانات في جدول `wp_service_ratings` بالحقول التالية:

| الحقل | الوصف |
|-------|-------|
| id | معرّف التقييم |
| customer_name | اسم العميل |
| customer_phone | هاتف العميل |
| customer_email | بريد العميل |
| service_name | اسم الخدمة |
| rating | التقييم (1-5) |
| comment | التعليق |
| ip_address | عنوان IP |
| is_approved | حالة الموافقة |
| created_at | تاريخ الإنشاء |
| updated_at | آخر تحديث |
